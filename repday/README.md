# 하루돋움 디자인 v21

## 실행
VS Code에서 이 폴더를 열고 터미널에서 아래 명령을 실행합니다.
python -m http.server 8000 --bind 127.0.0.1
브라우저에서 http://localhost:8000/ 을 엽니다.

## 등급
- 초보는 기존과 같은 하루 3종목, 종목당 2세트, 8회 또는 20초입니다.
- 중수는 하루 6종목, 종목당 4세트, 12회 또는 30초입니다.
- 고수는 하루 총 10종목, 종목당 6~10세트 선택, 16회 또는 40초입니다. 기본은 6세트입니다.
- 등급은 상단에서 언제든 바꿀 수 있습니다. 등급과 세트 수별 진행 기록을 따로 저장합니다.
- 기존 버전의 기록은 당시 3종목 기준으로 완료를 집계합니다. v5의 새 체크 목록은 별도로 시작합니다.

## 몸 상태와 배지
3일 전체 완료를 루틴 1회로 계산하고 4회마다 몸 상태를 묻습니다.
첫 운동, 누적 30·100·300·1000세트, 3일 루틴 4회, 중수 하루치 3회, 고수 하루치 3회에 운동 배지를 표시합니다.
운동 체크를 취소하면 배지도 현재 기록에 맞춰 다시 계산합니다.
같은 앱 주소로 여러 기기에서 접속할 수 있습니다. 브라우저마다 별도 세션으로 운동 기록, 배지, 몸 상태와 식단을 관리합니다. 배지 화면에 이 브라우저의 세션 코드가 표시됩니다.

## 기존 GitHub 앱 업데이트
https://github.com/28konm60/repday/tree/main/repday 에서 Add file → Upload files를 선택합니다.
repday 폴더의 변경 파일을 main 브랜치에 반영합니다.
새 버전을 배포할 때는 sw.js의 캐시 버전과 index.html 하단의 표시 버전을 올립니다.
앱은 열거나 화면으로 돌아왔을 때, 그리고 열린 상태에서 5분마다 업데이트를 확인합니다.
휴식 타이머, 음성 안내, 몸 상태 입력이 끝나면 새 버전으로 자동 전환합니다.
v7에서 처음 전환할 때는 앱을 닫았다 다시 열어야 할 수 있습니다.
음성은 남성 목소리로 운동 방법을 읽습니다. 세트와 횟수는 화면에서 확인합니다.
음성 파일을 불러올 때 인터넷 연결이 필요합니다.

## 새 화면
휴대폰 하단 메뉴로 운동·기록·몸 상태·배지로 이동합니다. PC에서는 운동과 기록을 두 열로 표시합니다. 완료된 운동에는 색상과 완료 표시가 나타납니다.

## 식단
만 6~19세는 나이만 입력하면 분량 계산 없이 세 끼 메뉴와 조리법을 볼 수 있습니다. 만 20~78세는 신체 조건, 활동량과 목표에 따라 세 끼 메뉴의 재료 양을 조정합니다. 아침 9개, 점심 8개, 저녁 8개 메뉴를 576가지로 조합할 수 있습니다. 다른 식단 추천 버튼을 누르면 576가지 조합을 무작위 순서로 한 번씩 보여줍니다. 같은 브라우저에서 다시 열면 마지막 식단과 남은 추천 순서를 복원합니다. 식단 복원용 분량, 목표와 추천 순서를 저장하며 나이, 키, 체중, 성별은 저장하지 않습니다.
분량은 [Mifflin–St Jeor 추정식](https://pubmed.ncbi.nlm.nih.gov/2305711/)을 참고한 메뉴 예시입니다. 익힘 온도는 [FoodSafety.gov](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)를 참고했습니다.
영양값은 [USDA SR28](https://fdc.nal.usda.gov/download-datasets/)의 식품 100g당 값과 조리 전 재료 및 양념의 무게를 사용해 추정합니다. 성인은 카드에 표시된 분량, 만 6~19세는 공통 기본 레시피가 기준입니다.
음식 사진은 [Unsplash 라이선스](https://unsplash.com/license)에 따라 사용하며, 각 카드에 촬영자와 원본 링크를 표시합니다.

## 이메일 계정 설정
1. [Firebase Console](https://console.firebase.google.com/)에서 하루돋움 프로젝트에 웹 앱을 추가합니다.
2. Authentication의 로그인 제공업체에서 이메일/비밀번호를 사용 설정합니다.
3. Authentication 설정의 승인된 도메인에 28konm60.github.io를 추가합니다.
4. 웹 앱의 공개 Firebase 설정 객체를 auth-config.mjs에 넣습니다. 관리자 인증 정보나 서비스 계정 키는 넣지 않습니다.
5. 배포 후 이메일 인증, 비밀번호 재설정, 서로 다른 두 기기의 로그인과 기기별 로그아웃을 확인합니다.

공개 웹 앱 설정이 없으면 로그인 버튼은 숨겨집니다. 운동 기록, 배지와 식단은 각 브라우저에 따로 저장됩니다.

## 축구 홈
기본 첫 화면은 축구 훈련입니다. 볼 컨트롤, 드리블, 패스·첫 터치, 슈팅·마무리, 풋워크에 각각 3가지 훈련이 있습니다. 완료 기록은 한국 시간 날짜별로 브라우저에 저장됩니다. 기존 맨몸 운동은 보조 운동 메뉴에서 사용할 수 있습니다.
